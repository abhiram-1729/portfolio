# Realtime AI Backend (Gemini Pro + Supabase)

This is a high-performance, asynchronous Python backend simulating a real-time conversational session.
It features WebSockets for low-latency communication, Supabase for persistence, and Google Gemini Pro for LLM intelligence with tool calling capabilities.

## Features
- **Real-time Streaming**: Instant feedback using WebSocket text streaming.
- **Complex LLM Interaction**: Uses Gemini's native tool-calling for simulated external data fetching (e.g., Weather lookup).
- **Persistence**: Usage of Supabase (PostgreSQL) to store session metadata and detailed event logs.
- **Post-Session Automation**: Automatically triggers a background task upon client disconnect to summarize the conversation and update the session record.

## Setup Instructions

1. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

2. **Environment Configuration**
   Create a `.env` file (copied from `.env.example`) and fill in your API keys:
   ```env
   SUPABASE_URL=your_supabase_url
   SUPABASE_KEY=your_supabase_anon_key
   GOOGLE_API_KEY=your_google_ai_studio_api_key
   ```

3. **Database Setup**
   Go to your Supabase SQL Editor and run the following schema:

   ```sql
   -- Sessions Table
   create table if not exists sessions (
     session_id uuid primary key default gen_random_uuid(),
     user_id text,
     start_time timestamptz default now(),
     end_time timestamptz,
     summary text,
     duration_seconds integer
   );

   -- Event Logs Table
   create table if not exists event_logs (
     id bigint generated by default as identity primary key,
     session_id uuid references sessions(session_id) on delete cascade,
     timestamp timestamptz default now(),
     event_type text not null check (event_type in ('user', 'ai', 'tool', 'system')),
     content text,
     metadata jsonb
   );
   ```

## Running the Application

1. **Start the Backend Server**
   ```bash
   uvicorn main:app --reload --port 8000
   ```
   The server will start at `http://127.0.0.1:8000`.

2. **Start the Client**
   Open `index.html` in your web browser. You can serve it via a simple HTTP server:
   ```bash
   python3 -m http.server 3000
   ```
   Then navigate to `http://localhost:3000`.

## Usage
1. Open the Chat Interface.
2. It will automatically connect to a new session.
3. Type a message, e.g., "What is the weather in San Francisco?".
4. Observe the tool execution and streaming response.
5. Close the tab or refresh to end the session.
6. Check your Supabase table `sessions` to see the generated summary and duration!

## Design Choices

- **FastAPI**: Chosen for its native asynchronous support, type safety, and efficient WebSocket implementation.
- **Google Gemini Pro (1.5/2.0)**: Used for high-quality reasoning and native support for tool calling and streaming.
- **Asynchronous Persistence**: All database operations use `asyncio.to_thread` to stay non-blocking within the FastAPI event loop.
- **Post-Session Logic**: Uses `asyncio.create_task` during the WebSocket disconnect event. This ensures the summarization job (fetching history, calling LLM, updating DB) runs reliably in the background without blocking the server.
- **State Management**: The conversation history is maintained in-memory during the session and persisted in granular logs for auditing and summarization.
